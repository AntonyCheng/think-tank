# EvidenceQuality V1

## 定位

`EvidenceQualityAssessment` 是最终报告交付前的确定性证据检查，与 AO 的语义内容验收并列。它不调用模型、不访问网络，同一份引用结果和 EvidenceBundle 必须得到同一输出。

任务快照分别保存：

- `contentAcceptance`：AO acceptance 的通过状态和未满足项；
- `evidenceQuality`：结构化指标和稳定警告码；
- `warnings`：两者消息的兼容合并视图。

任一检查产生警告时，报告仍交付，任务状态为 `completed_with_warnings`；只有研究执行本身失败才进入 `failed`。

## 指标口径

- **引用覆盖率**：含数字、百分比、金额、日期或量化单位的段落中，带 EvidenceLedger 已验证链接的比例；目标 80%。
- **有效链接率**：正文唯一 HTTP(S) Markdown 链接中，存在于本次公开证据允许列表的比例；目标 100%。
- **来源去重**：所有步骤的公开来源数、按规范化 URL 合并后的独立来源数、重复数和重复率。至少 4 条观察且重复率高于 25%时警告。
- **域名多样性**：独立来源的规范化 hostname 数；独立来源不少于 3 个却少于 2 个域名时警告。
- **来源类型**：按 hostname 确定性分为政府、学术、组织、商业和其他。

分母为零的比例使用 `null`（前端显示“不适用”），不会伪造 0% 或 100%。

## 有效链接的边界

V1 的“有效”指链接语法有效且属于本次证据包，不代表目标网站此刻可访问。平台刻意不做在线 HEAD 探测，因为代理、限流、登录墙、反爬和临时故障会产生不稳定结果。网络可达性或内容快照验证应作为后续独立能力加入，不能改变 V1 指标语义。

## 前端

顶部指标分别显示“内容验收”和“证据质量”。警告报告的交付卡片分区呈现两类问题；证据区同时显示覆盖率、有效链接率、去重结果、域名数和来源类型。旧任务缺少新增字段时继续读取兼容 `warnings`。
