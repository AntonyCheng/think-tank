# TT-004.1 时间语义与综合模式收尾

## 状态

已于 2026-07-29 完成。

## 问题

真实任务“帮我分析一下美国近三年经济情况”暴露出两个边界缺口：

- 当前日期已注入 AO 与 GPTR，但“近三年”没有确定语义，AO 将其编排为 2023—2025。
- 最终步骤声明了依赖并引用上游输出，但 AO 未显式填写研究模式，首次执行仍继承 `standard`，直到验收返工才切换为 `synthesis`。

## 决策

- “近 N 年”“最近 N 年”“过去 N 年”默认包含当前年度截至任务启动日期，并向前覆盖 N-1 个年度。
- 只有用户明确要求“完整自然年”或“完整年度”时才排除当前年度。
- 解析出的年份范围进入 AO 编排提示；若工作流明确声明冲突范围，预检失败并沿用现有机制自动重新编排一次。
- 未显式声明研究模式的终端普通步骤，在存在 DAG 依赖且 `task` 引用了依赖步骤的 `output` 时，平台将其归一化为 `synthesis`。
- AO 显式声明的 `standard`、`deep` 或 `synthesis` 仍优先，避免把需要继续联网补研的后续步骤误判为综合。

## 验证

- 真实旧工作流被识别为 `2023-2025` 与期望 `2024-2026` 冲突。
- 同一工作流的最终步骤首次解析为 `synthesis`。
- Node 122 项、Python 70 项、类型检查、构建及 V1 acceptance 全部通过。
