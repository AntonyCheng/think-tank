# AO × GPT Researcher Integration TODO

更新日期：2026-07-30  
能力基线：Agency Orchestrator `0.12.1`、GPT Researcher `0.16.0`

本清单用于逐项制定 Plan 和实施，不代表所有能力都应同时开启。基本边界保持不变：

- AO 是唯一控制面，负责专家、完整 `systemPrompt`、DAG、人工节点、条件、循环、验收和返工。
- GPTR 是研究执行面，负责搜索、抓取、深度研究、来源策展、证据与报告草稿。
- 本平台只做适配、状态持久化、可观测性、安全和交付，不复制或修改两个上游项目源码。
- 每项默认保持现有“网页标准研究”兼容；新增能力通过版本化配置和显式开关启用。

优先级：`P0` 为核心地基，`P1` 为主要能力增强，`P2` 为高级能力。依赖项未完成时，不开始下游实现。

## 阶段 1：发挥 GPTR 深度研究核心能力

### [x] TT-004 标准、深研、综合三种执行模式

**优先级：** P0　**依赖：** TT-003

**完成标准：** 三种模式有契约测试；存在任务级总并发预算，避免“AO 并发 × GPTR 并发”失控；超限时可降级而非拖垮服务。

**实施 Plan：** [TT-004 标准、深研、综合三种执行模式](plans/tt-004-standard-deep-synthesis-modes.md)

### [x] TT-005 步骤级 `EvidenceBundle`

**完成标准：** 证据包随任务持久化并可供下游综合步骤复用；最终引用只接受证据包中的来源；私有来源不会生成公开链接。

**实施 Plan：** [TT-005 步骤级 EvidenceBundle](plans/tt-005-step-evidence-bundle.md)

**实施 Plan：** [TT-006 来源策展与确定性质量指标](plans/tt-006-source-curation-quality-metrics.md)

**实施 Plan：** [TT-007 结构化研究进度与成本](plans/tt-007-structured-progress-cost.md)

## 每个 TODO 的统一完成定义

一个条目只有同时满足以下条件才能勾选：

- 范围与非目标已经在实施 Plan 中写明，且不修改 AO/GPTR 上游源码。
- API、持久化模型、事件和前端行为保持兼容，或提供明确的版本迁移。
- 正常路径、并发/超时/失败路径和敏感信息处理均有测试。
- 设置中的密钥永不通过读取接口、日志、事件或任务快照返回。
- 文档和 `.env.example`（若涉及配置）同步更新。
- 自动化验证通过，并完成一次可复现的人工验收。
